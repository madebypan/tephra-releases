# Tephra releases

This repository contains only the public, signed release artifacts for
[Tephra](https://tephranote.com). The application source code is maintained in
a separate private repository.

Use [tephranote.com](https://tephranote.com) to download Tephra. Release files
are published here automatically after the macOS build passes tests, Developer
ID signing, Apple notarization, and Tauri updater signing.
